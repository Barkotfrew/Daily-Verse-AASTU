# Benaiah Typeface

- Typeface: Benaiah Bold
- Designer: Abraham Fikadu
- File: `Benaiah.ttf`, supplied by the project owner and included unchanged.
- The publisher announced Benaiah as an open-source font offered freely: <https://t.me/s/Type_Habesha?before=977>

The reading interface uses Benaiah for book and chapter headings. Verse text remains in Noto Serif Ethiopic for readability. Noto Sans Ethiopic is the heading fallback for Ethiopic characters not included in this Benaiah file.
